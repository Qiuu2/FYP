# tasks/ —— 任务与回传留档

**为什么有这个目录**：避免「我以为发过了」「这个谁负责来着」这类问题。
每一次派给组员的任务、每一次回传，都在这里留一份，带日期。

## 目录结构

```
tasks/
├── README.md              ← 本文件
├── 任务单/                 ← 派出去的（按 姓名_周次_日期 命名）
├── 回传/                   ← 收回来的（按 姓名_任务号_日期 命名）
└── 任务台账.md             ← 总表：谁、什么、何时截止、状态
```

## 规则

1. **派任务**：任务单写进 `任务单/`，同时在 `任务台账.md` 添一行
2. **收回传**：原样存进 `回传/`，**不要改内容**（R6 状态诚实），在台账里更新状态
3. **命名**：`任务单_賈贇_W2_2026-09-22.md`、`回传_賈贇_J2_2026-09-18.csv`
4. **不改历史**：任务单发出后若要改，新建一份带新日期的，旧的保留

## 状态取值

| 状态 | 含义 |
|---|---|
| `待开始` | 已派出，未开工 |
| `进行中` | 已开工 |
| `已回传` | 产物收到，未复核 |
| `已复核` | 经 R4 双人复核通过 |
| `逾期` | 超过截止日未回传 |
| `作废` | 任务取消（须注明原因） |
