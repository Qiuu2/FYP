## 二、新方案：拉全量，本地归类

你的探针已经证明单次请求能把 109 条全取回来，所以直接走这条路：

**对每个 城市 × 季度**：

1. 用 `AREA[StudyFirstPostDate]RANGE[起,止]` 拉回该季度**全部记录**（不带 Phase 过滤）
2. 本地读每条记录的 `phases` 字段
3. 按取值归类，**「无此字段」单独算一档**

调用量：2 城 × 40 季 = **80 次**（比原方案的 480 次还少）。

**产物**：`raw/clinicaltrials_phase_by_quarter.csv`

```
city,quarter,phase,count
hk,2024Q1,NA,73
hk,2024Q1,NO_PHASE_FIELD,14
hk,2024Q1,PHASE3,12
...
```

`phase` 列的取值：`NA` / `NO_PHASE_FIELD` / `EARLY_PHASE1` / `PHASE1` / `PHASE2` / `PHASE3` / `PHASE4`
（如果实际数据里出现了多值组合，照实记成 `PHASE1|PHASE2` 这样，别合并）
