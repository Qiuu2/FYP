## 二、J4 —— 脚本现在你有了

拉下仓库后：

```powershell
cd <你clone的位置>\FYP
python scripts\ct_phase_probe.py
```

它会把 2024Q1 香港的全部临床试验记录拉回来，统计 `phases` 字段的真实取值组合，
直接打印「多值组合有多少」「无该字段的有多少」。

**要解决的问题**：你测出总数 109，但分项只加到 95（含你发现的 `EARLY_PHASE1`），差 14。

两种可能，靠逐条 count 永远分不出来：

- **(a)** `phases` 是多值字段（如 `["PHASE1","PHASE2"]`），而 `AREA[Phase]PHASE1` 只匹配单值
- **(b)** 有些试验根本没有 `phases` 字段

⚠️ 线索指向 (a)：如果是「包含」匹配，分项和应该**大于**总数；现在是小于，说明组合期别两边都没数到。

**产物**：整段输出粘回来，不用自己下结论。

## 三、diff_safe —— 现在有对照物了

仓库版 `collect_all.py` 是 **32,908 字节**。你本地那份是 33,037 字节，多 129 字节。

拉下仓库后：

```powershell
cd <你clone的位置>\FYP
python scripts\diff_safe.py --old scripts\collect_all.py --new "C:\你本地的路径\collect_all.py"
```

（如果脚本参数名不是 `--old/--new`，直接 `python scripts\diff_safe.py --help` 看一下）

它会把疑似密钥的长字符串遮蔽掉再输出 diff，**所以结果可以直接发回来，不会泄露**。

**为什么非查不可**：仓库现在是**公开的**。如果你那份写死了 API key 而我们直接合并进去，
密钥就进了 git 历史 —— 删文件也没用，得重写整个历史。所以 **J4 全量重采之前必须先过这一关**。

**产物**：diff_safe 的输出粘回来。
