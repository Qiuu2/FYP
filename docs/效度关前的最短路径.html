拦路虎只有一个：TAI 规模维是空的

不是「12 个指标差 9 个」。按提案自己的频率规则拆开算，其中 6 个根本不阻塞输出。真正卡住效度关的只有一处，而它比我此前判断的便宜一个数量级。

为什么大部分指标不阻塞

§4.2 写死了：「年度指标只进入年度剖面、绝不内插为季度」。所以季度指数只能由季度指标合成。把 12 个指标按频率拆进七个维度：

没有规模维，效度关跑不了

步骤①效度关一要求重现「金融科技双高、生物医药高研究低商业、AI 人才陡升在前」。最后那句检验的正是规模维——没有它，这一关无从查起。

而提案写死了：「指数不过效度关，后续分析不展开」。所以规模维是整条链路的第一个死结，不是十二分之二。

三件事，做完就能跑步骤①

按「不做就出不了东西」排序。三件加起来大约一天。

01

指标 1 · 研究者存量

≈ 930 次调用 · 半天

口径（附录 A）：近三年在港机构署名发文的唯一作者数，滚动窗口；机构含八大＋公营研发，新加坡侧用 NUS＋NTU。

我此前说它「调用量大要先估排期」，是错的。实际算过：要遍历的 works 就是已采 papers 分母的同一批，184 635 篇，每页 200 条 →约 923 次调用。OpenAlex 免费额度一天十万次，半天跑完。这个误判让最关键的一件事被推迟了好几轮。

做法必须是「一次拉全 + 本地滚动」，不能按窗口反复请求。
按 40 期各自回溯三年去请求，等于把同一批 works 重复读约 12 倍，会变成几万次调用。正确做法是把 2015–2024 的 authorships 一次性拉下来，每篇只读一次，然后在本地按（单元, 季度）建作者集合，40 个滚动窗口全部用集合并集算出来，零额外调用。

filter = primary_topic…（沿用现有白名单）
       + authorships.institutions.country_code:hk|sg
       + from_publication_date / to_publication_date
select = id,publication_date,authorships.author.id,authorships.institutions
cursor = *          per_page = 200

真正的风险不是调用次数，是响应体积——生物医药的大型合作论文 authorships 可能有几百个作者。建议先只跑 ai/hk 一个单元试水，量到实际耗时再放全量。

02

指标 7 · 补 fintech 分子

80 次调用 · 十分钟

根因找到了，不是漏跑，是代码分支里就没写。collect_all.py 的 mod_papers() 里：

if flt:        # AI / biomed 走这支（学科白名单）
    …算分母 n
    …算分子 ni（+countries_distinct_count:>1）
    rows_n.append(…)
    rows_i.append(…)   ← 分子只在这里 append
else:          # fintech 走这支（关键词口径）
    …算分母
    rows_n.append([ind+"_kw", …])
                       ← 没有 rows_i.append，分子整个缺失

所以分母 240 行（6 单元）、分子 160 行（4 单元）。修法是在 else 分支里补一次带 countries_distinct_count:>1 的调用，增量 2 城市 × 40 季 = 80 次。

为什么必须做：效度关一要检验「金融科技双高」，需要 fintech 的 TAI。网络维是 TAI 目前仅有的成熟维度，缺这两个单元，fintech 那一格就查不了。

03

指标 11 · 切成季度

本地 · 半小时

clean/listings_18a_by_year.csv 是年度的，但原始件 raw/p3_hkex_listings.txt 里每条都带日期（XtalPi Holdings,13/6/2024,…）。零采集成本，纯本地加工。

口径提醒：18A 是生物科技、18C 是特专科技，都只有香港。步骤②已声明「上市公司口径因新加坡科技龙头多在美股上市而不对称，采用合并口径或降为定性参照」——所以这个指标本来就是单边的，不用为新加坡侧发愁。

明确不做的

这些该做，但排在效度关之后。现在做就是无用功——效度关不过，步骤②③根本不展开。

  • 指标 3、4、5、6、10、12 —— 六个全是年度指标，按 §4.2 只进年度剖面（步骤②），不阻塞步骤①③。这六个正好占了「差 9 个」里的三分之二。
  • 指标 2 GitHub 活跃开发者 —— 我上一轮说它「性价比最高、今天就能定」，收回。它和指标 1 同属规模维，有一个维度就成立；而指标 1 的口径、白名单、数据源全部现成，指标 2 还要先解决怎么枚举驻港账户（Search API 有 1000 条上限、location 是自填自由文本，HK／香港／Hong Kong SAR 都要处理）。留作规模维的第二个指标，不是现在。
  • 继续精修专利 —— 指标 8 已收口，三条序列都在。CPC 是否收紧为 inventive-only 抽样证据不足，维持现状留痕即可。

一个必须先定的口径

季度指数由哪几个维度合成？

上面那张表推出来的结论是：TAI 季度 = 规模 ＋ 质量 ＋ 网络（流动维排除）、IDI 季度 = 创新 ＋ 商业（资本维排除）。

这是从「年度指标只进入年度剖面」推导的，但提案没有明写「维度可以因频率缺席」。§4.2 只说「维度内等权、维度间等权」，没处理频率不齐的情况。

不确认这条，「还差多少数据」就没有答案——因为「够」的标准没定义。组会五分钟能定，而它决定后面所有采集的取舍。
